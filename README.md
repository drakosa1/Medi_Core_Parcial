## Organización del equipo

Somos 7 integrantes distribuidos en tres células y un GitMaster:

- Dominio POO (2 integrantes): clases, atributos, métodos y validaciones. Rama: feature/dominio.
- Servicios y datos (2 integrantes): lógica del sistema y persistencia. Rama: feature/servicios.
- Interfaz (2 integrantes): pantallas, menús e interacción con el usuario. Rama: feature/ui.
- GitMaster (1 integrante): revisa los Pull Requests, integra los cambios y ejecuta las pruebas finales.

Cada integrante realizará sus propios commits y abrirá su Pull Request. El GitMaster coordinará las fusiones hacia main.
